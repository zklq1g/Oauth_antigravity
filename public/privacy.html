Privacy Policy

Last updated: October 2026

1. Information We Collect

Antigravity Token Collector facilitates user-initiated Google OAuth authorization. When you authenticate via Google, the application receives standard authentication tokens (refresh token, access token) and basic profile identifiers (email address, name).

2. How Information is Used

The tokens and identifiers collected are used exclusively for personal developer integration and API quota pooling with Antigravity Tools. We do not sell, rent, or monetize any user data.

3. Data Storage & Security

Tokens generated through this service are processed ephemeral in serverless compute environments and displayed directly to the authorized user. No user data or tokens are stored on our servers or databases.

4. Third-Party Services

This application communicates with Google APIs using Google OAuth 2.0 standards. Use of information received from Google APIs adheres to the Google API Services User Data Policy.

5. Revoking Access

You can revoke access to this application at any time through your Google Account security settings at Google Account Permissions.
